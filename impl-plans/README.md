# Implementation Plans

Plans in this directory convert accepted design documents into concrete delivery slices.

Conventions:

- `active/` lists in-flight or not-yet-archived plans
- archived plans live under `completed/`; update cross-links when moving a file from `active/` to `completed/`
- each plan should reference one or more design docs
- plans should be incremental and independently verifiable
